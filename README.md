# Knowi (knowi)

Knowi is an analytics and business intelligence platform with native integration to NoSQL, SQL, and REST API data sources, providing AI-powered analytics, embedded dashboards, and natural language querying.

## APIs

### Knowi Management API
The Knowi Management API enables programmatic administration of users, groups, and dashboards in a Knowi workspace using OAuth 2.0 bearer tokens.

### Knowi Push Data API
The Knowi Push Data API enables real-time data ingestion to and pull retrieval from Knowi datasets, with SQL-like filters and multiple export formats.
